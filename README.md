# ФПиКЭИАС — статическая версия для GitHub Pages

Проект полностью адаптирован под **GitHub Pages** и работает как статический сайт на:

- `HTML`
- `CSS`
- `JavaScript`

Backend (`Flask`/`Python`) для публикации на GitHub Pages **не требуется** и **не используется**.

---

## Что уже сделано

- Логика расчётов перенесена в клиентский JavaScript.
- Основная страница: `docs/index.html`
- Стили: `docs/assets/style.css`
- Скрипты: `docs/assets/app.js`
- Все вычисления выполняются в браузере.

---

## Структура проекта (для деплоя)

```text
ФПиКЭИАС/
└── docs/
    ├── index.html
    └── assets/
        ├── style.css
        └── app.js
```

> Для GitHub Pages используется папка `docs/`.

## Локальный запуск (проверка перед публикацией)

### Вариант 1: Python HTTP Server

Из корня проекта:

```bash
python -m http.server 8080
```

Открыть в браузере:

```text
http://localhost:8080/docs/
```

### Вариант 2: VS Code Live Server

Откройте `docs/index.html` через Live Server.

## Публикация на GitHub Pages

1. Запушьте изменения в репозиторий (обычно ветка `main`).
2. Перейдите в GitHub:  
   `Settings` → `Pages`
3. В разделе **Build and deployment**:
   - `Source`: **Deploy from a branch**
   - `Branch`: `main`
   - `Folder`: `/docs`
4. Сохраните настройки и дождитесь деплоя.

Итоговый URL будет вида:

```text
https://<username>.github.io/<repo-name>/
```

---

## Важные правила для статической версии

1. Нельзя использовать серверные маршруты (`Flask`, `url_for`, API-эндпоинты backend).
2. Все пути должны быть относительными:
   - `./assets/style.css`
   - `./assets/app.js`
3. Все расчёты и интерактивность — только в JavaScript на клиенте.
4. Для GitHub Pages главная точка входа — `docs/index.html`.

## Примечание

Старый backend-код можно оставить в репозитории для истории, но GitHub Pages его не исполняет.  
Если нужен серверный функционал — используйте отдельный хостинг для API, а фронтенд оставляйте в `docs/`.
