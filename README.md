Веб-приложение для расчёта показателей экономической эффективности ИАС
======================================================================

Данное приложение представляет собой набор из 8 калькуляторов, реализующих методики расчёта экономической эффективности ИАС.

## Структура проекта
```
myapp/
│
├── app.py                 # главный файл запуска и функции рендеринга страниц
├── modules/               
│   ├── module1.py         # Экономическая эффективность ИАС
│   ├── module2.py         # Эффективность создания АРМ
│   ├── module3.py         # Предварительное обоснование ИАС
│   ├── module4.py         # Годовой эффект от внедрения ИАС
│   ├── module5.py         # Калькуляция себестоимости ПО
│   ├── module6.py         # Себестоимость программного продукта
│   ├── module7.py         # Обзор ПО для ССП (Cognos, Geac, IBM, ARIS)
│   └── module8.py         # Обзор ПО для ССП (SAP, Oracle, Hyperion, Business Studio)
│
├── templates/             # шаблоны HTML
│   ├── base.html
│   ├── index.html
│   └── module.html
│
└── static/                # статические файлы (CSS)
    └── style.css
```
# Установка и запуск
1. Убедитесь, что у вас установлен Python 3.7 или выше.

2. Установите Flask:
    ```
    pip install flask
    ```
3. Перейдите в папку с проектом и запустите:
    ```
    python app.py
    ```
4. Откройте браузер и перейдите по адресу: http://127.0.0.1:5000

Описание модулей
------------------

| Модуль | Название | Содержание |
|--------|----------|------------|
| 1 | Экономическая эффективность ИАС | Расчёт годового экономического эффекта, срока окупаемости, затрат на разработку, трудоёмкости ПО |
| 2 | Эффективность создания АРМ | Затраты на разработку, текущие затраты, экономия от внедрения, годовой и интегральный эффект |
| 3 | Предварительное обоснование ИАС | Критическое число проектных решений Nкр, приведенные затраты, показатели эффективности |
| 4 | Годовой эффект от внедрения ИАС | Снижение себестоимости, экономия от сокращения цикла, срок окупаемости |
| 5 | Калькуляция себестоимости ПО | Расходные материалы, прямая зарплата, затраты на ПЭВМ, накладные расходы |
| 6 | Себестоимость программного продукта | Трудоёмкость этапов, заработная плата, амортизация, электроэнергия, полная себестоимость |
| 7 | Обзор ПО для ССП (часть 1) | Характеристики и стоимость Cognos Metrics Manager, Geac, IBM WebSphere, ARIS BSC |
| 8 | Обзор ПО для ССП (часть 2) | Характеристики и стоимость SAP SEM, Oracle BSC, Hyperion, Business Studio |

Интерфейс
---------

* На главной странице отображается список модулей в виде карточек.
* При переходе в модуль открывается страница с формой для ввода исходных данных.
* Результаты расчётов отображаются в правой колонке, структурированы по разделам (можно сворачивать/разворачивать).
* Дизайн адаптивный: на узких экранах колонки располагаются вертикально.

Примечания
----------

* Во всех модулях используются числовые поля с шагом, допускающим десятичные значения.
* Для корректной работы модулей, связанных с валютой (7 и 8), предусмотрены поля для ввода курсов доллара и евро.
* Значения по умолчанию взяты из примеров в методических пособиях.
